# نسخه V5 رفع کرش موبایل

این نسخه شامل دو پروژه اندروید است:

- `mobile-client`: کلاینت موبایل کاربر/سمن، صفحه ورود سمن را باز می‌کند.
- `mobile-admin`: ادمین موبایل، صفحه مشاهده میدانی را باز می‌کند.

فایل اصلی workflow یعنی `.github/workflows/android.yml` خروجی کلاینت کاربر را می‌سازد.

تغییرات رفع کرش:
- WebView داخل try/catch اجرا می‌شود تا اگر WebView گوشی خراب/غیرفعال باشد، برنامه بسته نشود و پیام خطا نشان بدهد.
- آیکون vector ساده شد تا روی گوشی‌های قدیمی باعث خطای runtime نشود.
- Hardware acceleration برای WebView غیرفعال شد تا روی GPUهای ضعیف کرش نکند.
- مسیر خروجی APK به صورت خودکار جست‌وجو و آپلود می‌شود.
- نسخه کلاینت با applicationId جدا ساخته می‌شود: `ir.javanrood.ngo.clientmobile`.

قبل از نصب نسخه جدید، نسخه قبلی را از گوشی حذف کن. اگر باز هم باز نشد، Android System WebView یا Chrome گوشی را آپدیت/فعال کن و logcat بگیر.
