# نسخه V58/V59 - تم سه‌بعدی و حساب کاربری

تغییرات انجام‌شده:

- اعمال تم جدید سه‌بعدی/گلس‌مورفیسم/نیومورفیسم روی نسخه ویندوز و موبایل.
- اضافه‌شدن تب «حساب و امنیت» برای ادمین.
- اضافه‌شدن تب «حساب کاربری» برای کلاینت سمن.
- امکان تغییر نام کاربری ادمین.
- امکان تغییر رمز عبور ادمین.
- امکان تغییر نام کاربری کلاینت کاربر.
- امکان تغییر رمز عبور کلاینت کاربر.
- نمایش قدرت رمز عبور.
- نگهداری آخرین زمان تغییر رمز و آخرین ورود.
- غیرفعال شدن ورود سریع کلاینت بعد از تغییر نام کاربری برای جلوگیری از ورود با کلید قدیمی.

مسیرهای مهم:

- `.github/workflows/windows-exe.yml` برای ساخت EXE ویندوز.
- `.github/workflows/android-admin.yml` برای ساخت APK ادمین موبایل.
- `.github/workflows/android.yml` برای ساخت APK کلاینت موبایل.

نام خروجی‌های GitHub Actions:

- `javanrood-mobile-admin-apk-v59-3d-account`
- `javanrood-mobile-client-apk-v59-3d-account`

نکته: قبل از نصب APK جدید روی گوشی، نسخه قبلی همان اپ را uninstall کن یا اجازه بده با versionCode بالاتر به‌روزرسانی شود.
